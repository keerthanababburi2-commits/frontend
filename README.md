🚀 How to Run

Prerequisites

* Node.js and npm
* Git

Installation

1. Clone the repository:

git clone YOUR_FRONTEND_REPOSITORY_URL

2. Navigate to the frontend folder:

cd frontend

3. Install dependencies:

npm install

4. Start the development server:

npm run dev

5. Open the local URL shown in your terminal, usually http://localhost:5173.

🔗 Backend Integration

The frontend communicates with a separate backend built using Java, Spring Boot, REST APIs, and MySQL.

Configure the backend API URL in your frontend configuration according to your local or deployed backend.
